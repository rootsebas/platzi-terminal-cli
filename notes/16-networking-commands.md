# 🌐 Networking Commands in Linux

## Commands Used

- `ip a` (show network interfaces)
- `ip r` (show routing table)
- `ping` (check connectivity)
- `curl` (HTTP requests)
- `wget` (download files)
- `nmap` (scan ports)
- `traceroute` (trace network path)

## Description

- These commands allow interaction with network interfaces, servers, and web resources
- Useful for debugging connectivity, downloading data, and analyzing networks

## Examples

- `ip a` → display network interfaces and IP addresses
- `ip r` → show routing table and default gateway
- `ping www.google.com` → test connectivity to a host
- `curl www.google.com` → fetch HTML content
- `curl www.google.com > index.html` → save response to file
- `wget https://example.com/file.zip` → download a file
- `nmap localhost` → scan open ports on local machine
- `traceroute www.google.com` → show packet route

## Key Learnings

- `ip a` and `ip r` help understand network configuration
- `ping` is essential for checking connectivity and latency
- `curl` is powerful for API calls and HTTP requests
- `wget` is useful for downloading files from terminal
- `nmap` and `traceroute` are advanced tools for network analysis
- Networking commands are critical for debugging and DevOps tasks
