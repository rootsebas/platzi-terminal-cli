# 📄 Viewing Files with head, tail and less

## Commands Used

- `less` 100_curiosidades_linux.txt
- `head` 100_curiosidades_linux.txt
- `tail` 100_curiosidades_linux.txt
- `head -n 20` 100_curiosidades_linux.txt

## Description

- `less` → allows you to scroll through the file interactively
- `head` → shows the first lines of a file
- `tail` → shows the last lines of a file
- `head` -n 20 → shows the first 20 lines

## Key Learnings

- `less` is better for large files because it allows navigation
- `head` and `tail` are useful for quickly inspecting files
