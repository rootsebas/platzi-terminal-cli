# ✏️ Text Editors in Linux (Vim & Nano)

## Commands Used

- `vim file` (open file with Vim)
- `nano file` (open file with Nano)

## Description

- Vim and Nano are terminal-based text editors
- Vim is powerful but has a learning curve
- Nano is simple and beginner-friendly

## Vim Basics

Modes:
- **Insert mode** → press `i` to start typing
- **Command mode** → press `Esc` to execute commands

Common commands:
- `:w` → save file
- `:q` → quit
- `:wq` → save and quit
- `:q!` → quit without saving
- `dd` → delete current line
- `gg` → go to start of file
- `:n` → go to line number (e.g. `:4`)

## Nano Basics

Shortcuts:
- `Ctrl + O` → save file
- `Ctrl + X` → exit
- `Ctrl + K` → cut line
- `Ctrl + U` → paste line
- `Ctrl + G` → help menu

## Examples

- `vim notes.md` → open file in Vim
- `nano notes.md` → open file in Nano

## Key Learnings

- Vim is ideal for advanced users and efficiency
- Nano is easier for quick edits and beginners
- Both editors are essential for working in servers or CLI-only environments
- Terminal editors are lightweight and fast compared to GUI editors
- Learning at least one is crucial for Linux productivity
