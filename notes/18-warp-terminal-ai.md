# 🤖 Warp (AI Terminal)

## Commands Used

- Natural language prompts (AI-powered)
- Standard terminal commands (enhanced with AI suggestions)

## Description

- Warp is a modern terminal with built-in AI
- Allows executing commands using natural language
- Enhances productivity by suggesting, explaining, and correcting commands

## Features

- Natural language execution (e.g. “create a snake game in Python”)
- Command suggestions and auto-correction
- Error explanations and debugging help
- Command previews before execution
- Split panes for multitasking
- Works with Linux environments (e.g. WSL on Windows)

## Examples

- Describe a task → Warp suggests the command
- Run commands → Warp explains output and errors
- Split terminal → work on multiple tasks simultaneously

## Key Learnings

- Warp simplifies terminal usage with AI assistance
- Reduces need to memorize complex commands
- Helps debug and understand errors faster
- Improves workflow for both beginners and advanced users
- Can be integrated into existing development environments
